# 💰 React Expense Tracker

A modern expense tracking application built with React.

## ✨ Features

- 💵 Budget Management
- 📊 Dashboard Overview
- 💳 Credit Card Management
- 📈 Expense Summary
- 🌙 Dark Mode
- 📱 Responsive Design

## 🛠 Tech Stack

- React
- Vite
- Tailwind CSS
- Context API
- Local Storage
- Git
- GitHub

## 🚀 Installation

```bash
npm install
npm run dev
```
